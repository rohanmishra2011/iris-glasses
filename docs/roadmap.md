# Roadmap

1. Engineering foundation
2. Reliable camera acquisition
3. Evaluated object-detection baseline
4. Short-term object tracking
5. Perception reliability and long-duration hardening
6. Observational event contracts
7. Long-term object and location memory
8. Consent-based familiar-person recognition
9. Optional IMU-based mobility perception
10. Deterministic task and context modeling
11. Optional speech and conversation
12. Navigation and caregiver integration

Each phase requires measurable exit criteria before downstream features begin.
The familiar-person phase now has an initial local implementation. Live
accuracy, enrollment usability, deletion controls, spoof resistance, and
Raspberry Pi performance still require acceptance testing before it can be
considered complete.

The intended personalization and spatial-learning architecture is described in
`adaptive-household-learning.md`. Language-model conversation is always on;
household learning, user modeling, and spatial mapping remain separate
evidence-based subsystems.
