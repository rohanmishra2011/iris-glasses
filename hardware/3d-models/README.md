# 3D model files

This folder contains the 3D-printable enclosure parts used for the current PUPIL smart-glasses prototype.

| File | Source file found on laptop | Notes |
| --- | --- | --- |
| `body.stl` | `Body4.stl` | Main body component found in the Desktop `Glasses` folder. |
| `rpi_lid_or_body2.stl` | `Body2.stl` | Second body/lid-style component found in the Desktop `Glasses` folder. The original filename did not explicitly say “lid.” |
| `rpi_casing_body.stl` | `RPiCasingBody.stl` | Raspberry Pi casing body. |

No file literally named “RPI lid” was found, so the likely matching body/lid STL was preserved with a descriptive filename.
